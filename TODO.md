На основе структуры репозитория, кода и истории коммитов есть несколько направлений для дальнейшего развития VoidSniffer:

**Производительность и масштаб**

- Добавить прогрессивную загрузку/пагинацию результатов Everything для дисков с миллионами файлов.
- Оптимизировать отрисовку TreemapControl: рендерить только видимые блоки, использовать DoubleBuffered/DPI-aware rendering, избежать полную пересборку дерева при навигации.
- Проверить поведение при >100k узлов: добавить профилирование и performance-тесты в тестовую инфраструктуру.
- Кэшировать результаты Everything во время навигации и добавлять явное событие инвалидации кэша.

**Надёжность и эксплуатация**

- Добавить глобальный обработчик необработанных исключений и запись логов в файл через System.Diagnostics.Trace/TraceListener.
- Проверять доступность Everything перед каждым запросом и давать пользователю действие «запустить/переподключить».
- Обрабатывать длинные пути (>MAX_PATH), отказы в доступе, недоступные диски и недостающие родительские папки без крашей UI.
- Унифицировать catch блоки: сейчас много узких catch, но нет общего результата для ошибок сканирования.

**Архитектура и сопровождение**

- Разделить MainForm на сервисы/модели представления: навигация, сканирование, фильтрация и отображение сейчас смешаны в одном модуле.
- Добавить DI или фабрики для EverythingDataProvider, ProgressiveTreeLoader, FilterService, NavigationController, чтобы тестировать их независимо.
- Формализовать контракты IEverythingFileSource и расширить unit-тесты для edge-cases.
- В csproj есть строка с двумя Compile-тегами на одной строке; стоит привести проектный файл к формату кроме скриптового редактирования.

**Безопасность**

- Проверять и нормализовать пути перед передачей в ShellContextMenu и запуском внешних команд.
- Не выполнять shell-действия без подтверждения пользователя; добавить явное журналирование.
- Ограничить запросы к Everything максимальным числом результатов и использовать фоновую обработку.

**UX/UI**

- Добавить keyboard shortcuts, поиск/фильтрацию в текущем дереве, экспорт отчёта, статус-бар со статистикой сканирования.
- Поддержать High DPI, тёмную тему, сохранение настроек пользователя.
- Показывать состояния загрузки, ошибки Everything и отмену операции явно.
- Улучшить tooltip: размеры в читаемых единицах, сортировка по размеру, отображение процентов от родителя.

**Тестиование и CI**

- Добавить интеграционные тесты с fake/mock IEverythingFileSource вместо реального Everything.
- Ввести performance-регрессии для построения дерева 500k+ элементов.
- Настроить Windows CI: сборка Debug/Release, запуск тестов, артефакты, версия сборки.
- Добавить code style analyzers и сборку с warnings-as-errors для поддержки C# 7.3+.

**Долгосрочно**

- Оценить переход с .NET Framework 4.8 на .NET 8 WinForms: лучшая производительность, память, long-path, асинхронность, современные NuGet-пакеты.
- Локализация интерфейса и документация пользователю, которых сейчас нет в проекте.
